-- Monthly Revenue + MoM Growth SELECT date_format(created_at, 'yyyy-MM') AS month, SUM(total_amount) AS monthly_revenue, SUM(SUM(total_amount)) OVER (ORDER BY month) AS cumulative_revenue, ROUND(value - LAG(value) OVER (ORDER BY month)) AS mom_growth FROM transactions WHERE payment_status = 'Success'

Key SQL features: LAG() window function · SUM() OVER · NULLIF for division safety

🔧 Engineering Challenge Solved
Windows: Spark throws UnsatisfiedLinkError when saving MLlib models (Hadoop NativeIO bug). Solution: keep model in Python memory, pass into foreachBatch closure — no disk writes. Also replaced Python UDFs with vector_to_array() to prevent EOFException crashes in Structured Streaming.

⚙️ Data Pipeline — 6 Spark Modules

📥
ingestion.py
Auto-detect Kaggle 2GB dataset OR generate synthetic data. Outputs Parquet to data/processed/.
🔍
eda.py
Generate 5 analysis charts: customer demographics, products, transactions, clickstream, cross-table.
⚡
transformations.py
6 Spark SQL queries: LTV, RFM, cohort retention, market basket, purchase velocity, affinity network.
🤖
ml_pipeline.py
Train all 3 models (RF Classifier, ALS, KMeans). Save JSON metrics. Evaluate with MLlib evaluators.
🌊
streaming.py
Stream simulator + consumer. Stream-Static JOIN with product catalog. Windowed aggregations and anomaly detection.
⚡
streaming_predictions.py
Phase 1: batch train RF. Phase 2: foreachBatch live scoring. In-memory model → no NativeIO crash.
# Run full pipeline (in order) python -m src.ingestion # → data/processed/ (Parquet) python -m src.eda # → outputs/eda/ (5 charts) python -m src.transformations # → outputs/sql_results/ (6 CSVs) python -m src.ml_pipeline # → outputs/ml/ (JSON metrics) python -m src.streaming # → outputs/streaming/ python -m src.streaming_predictions # → LIVE scores
